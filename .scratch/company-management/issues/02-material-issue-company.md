# 02: 領料單加單據公司

**What to build:** 讓領料單在建單時選擇單據公司（必填），並能在列表依公司篩選、顯示公司簡稱。從資料表回填、服務規則、API 到前端頁面一次打通：領料單新增公司外鍵（依 ADR-0001 只存 Id）、部署腳本後半（加欄位、用預設公司回填舊單據、改必填與外鍵）、建單與編輯的必填與鎖定規則、送簽時擋停用公司、列表與詳情顯示、編輯頁下拉。庫位不受公司限制，簽核流程不變。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 領料單表新增公司欄位與索引；既有資料庫腳本先允許空值、用預設公司回填、再改必填並加外鍵，可重複執行；同步資料庫專案與實體模型
- [ ] 新增與編輯領料單要求單據公司必填且公司必須存在；只有草稿與已退回可改單據公司（沿用現有「簽核中、已核准、已作廢不可編輯」規則，不新增狀態判斷）
- [ ] 送簽時所選公司已停用就被擋下並提示改選；已送簽、已核准、已作廢的單據不受之後的停用影響；其他送簽檢查與簽核引擎流程不變
- [ ] 列表與詳情回傳公司簡稱，詳情另含統一編號；列表新增「公司」篩選，與現有條件並用，可見範圍、排序、分頁不變
- [ ] 公司服務的「被引用過」判斷納入領料單，被領料單引用的公司不可刪除
- [ ] 前端：編輯頁新增公司下拉（只列啟用中；新單且只有一間時自動帶入；編輯草稿時原公司已停用則顯示「（已停用）」）、列表加公司欄位與篩選、詳情顯示簡稱與統編
- [ ] 現有領料單匯出若存在，多一欄公司簡稱（實作時確認有無匯出；若沒有，在 Comments 記錄）
- [ ] 調整共用種子資料，先建立一間公司，使既有測試仍可建單
- [ ] 延伸領料服務測試：公司必填、僅啟用中公司可選、草稿與已退回可改而其他狀態不可改、送簽時公司已停用被擋下、已送簽單據不受停用影響、列表依公司篩選與回傳簡稱
