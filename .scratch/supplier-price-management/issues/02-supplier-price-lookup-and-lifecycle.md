# 02: 填單查詢與供應商生命週期串接

**What to build:** 進貨單建單人填單時，能用供應商與料號查到目前的**供應商報價**作為參考（不自動帶入、不驗證、不阻擋）；供應商被停用時其報價查不到，供應商被刪除時報價一併刪除，不因有報價而擋下刪除。不改進貨單既有的儲存、送簽與簽核流程。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 提供填單查詢：輸入供應商 Id 與料號（完全相符），命中時回品名、單位、單價
- [ ] 查無報價、供應商已停用、供應商不存在，都回空結果，不是錯誤
- [ ] 查詢權限為「進貨單編輯」或「庫存編輯」其中之一，不要求供應商檢視；兩者都沒有則無法使用
- [ ] 停用供應商時其報價保留；重新啟用後查詢又能命中
- [ ] 刪除供應商時連同其全部報價一起刪除，不因存在報價而擋下
- [ ] 既有「被進貨單或庫存項目引用的供應商不能刪除」保護不變，仍擋下並提示改用停用
- [ ] 延伸供應商服務測試與 `SupplierPriceServiceTests`，覆蓋 spec 列出的填單查詢（命中、料號不完全相符、查無、停用、不存在）與刪除供應商連帶刪報價；同步調整因刪除規則改變而受影響的既有測試
- [ ] 進貨單的儲存、送簽與簽核行為不變（既有進貨單測試仍通過）
