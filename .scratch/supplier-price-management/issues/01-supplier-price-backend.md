# 01: 供應商報價後端：資料表、維護服務、權限與部署腳本

**What to build:** 讓有權限的人能透過 API 在某供應商之下新增、編輯、刪除**供應商報價**，並取得列表與單筆詳情。新增報價資料表與唯一規則，新增報價服務與控制器（不併入既有供應商服務），套用既有的供應商檢視、編輯、刪除三個權限與操作紀錄，並提供可重複執行的建表腳本。填單查詢與供應商刪除連帶處理留給 ticket 02，前端留給 ticket 03。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 新增報價資料表（接在供應商資料表之後，編號 4061）：供應商外鍵（連帶刪除）、料號（64）、品名（128）、單位（16）、單價（`decimal(12, 2)`）、備註、建立與最後修改的時間與人員；（供應商 Id＋料號）唯一索引；同步實體模型、DbContext 與資料庫專案
- [ ] 提供可重複執行的建表腳本（放 `docs/sql/`，資料表與索引先判斷是否存在才建立，含 `QUOTED_IDENTIFIER` 設定）
- [x] 欄位驗證：料號、品名、單位、單價必填；長度限制照資料表；單價大於 0 且最多兩位小數；不合規定被擋下並有明確訊息
- [x] 同供應商的料號不可重複，重複被擋下並有明確訊息；不同供應商可同料號；品名可重複
- [x] 新增、編輯（含修改料號，排除自己後仍不可與同供應商其他報價重複）、刪除；改價直接覆蓋，不保留歷史
- [x] 供應商不存在時，新增、編輯、刪除與列表都回「找不到供應商」；供應商已停用仍可維護
- [x] 列表：在某供應商之下，顯示料號、品名、單位、單價、備註、最後修改時間；關鍵字比對料號與品名；預設依料號排序；分頁；可取得單筆完整資料
- [ ] 套用權限：供應商檢視（4060）管列表與詳情、供應商編輯（40600）管新增與編輯、供應商刪除（40601）管刪除；新增、編輯、刪除寫入操作紀錄，不走簽核，不新增權限碼
- [x] 新增 `SupplierPriceServiceTests`（SQLite 記憶體庫、假使用者），覆蓋 spec「Testing Decisions」中維護與列表相關的規則
- [x] 更新 `docs/inventory/GLOSSARY.md`（若出現新術語）

偏離 ticket／spec 的決定（spec 沒有明說，實作時補的）：

- 備註長度上限 256；單價上限 9,999,999,999.99（對應 `decimal(12, 2)`）。
