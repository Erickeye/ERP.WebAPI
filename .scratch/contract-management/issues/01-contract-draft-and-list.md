# 01: 合約單草稿與基本列表（後端）

**Spec:** `.scratch/contract-management/spec.md`

**What to build:** 有「合約單編輯」權限的人可以建立合約單草稿（供應商合約或客戶合約），編輯、刪除草稿，檢視單筆，並在列表看到合約單（預設依起日由新到舊、分頁）。這張包含新的資料表與部署腳本、合約單單據類型、操作紀錄，以及合約單頁面需要的供應商、客戶、公司選單。簽核、附件與進階篩選由後續 ticket 處理。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 新增合約單資料表（供應商、客戶、公司外鍵皆限制刪除；單號唯一索引）、實體模型、DbContext、資料庫專案，並在 `docs/sql/` 提供可重複執行的建表腳本
- [ ] 新增單據類型「合約單」，沿用既有權限碼（檢視 3050、編輯 30500、刪除 30501），不新增權限碼
- [ ] 新增合約單狀態列舉（草稿、簽核中、已核准、已退回、已作廢）與 ViewModel
- [ ] 建立草稿時由序號服務產生單號
- [ ] 類型與對象恰好一個：供應商合約須有供應商且無客戶，客戶合約須有客戶且無供應商
- [ ] 必填（合約編號、簽約公司、對象、起訖日、合約總金額）與長度驗證，儲存草稿時即檢查
- [ ] 合約總金額大於 0 且最多兩位小數；迄日不得早於起日；起訖日可為過去日期
- [ ] 合約編號在非作廢單之間唯一（編輯排除自己、作廢單不佔用、不分類型），重複回明確訊息
- [ ] 停用的供應商與簽約公司不可選；客戶只檢查存在；不做期間重疊檢查
- [ ] 只有草稿可編輯與刪除（已退回可編輯，之後 ticket 送簽用）；其他狀態回含目前狀態的錯誤
- [ ] 單筆檢視與基本列表（欄位、預設依起日由新到舊、分頁）；查無資料回「找不到資料」
- [ ] 供應商、客戶、公司選單可供合約單頁面使用（供應商與公司排除已停用者）
- [ ] 新增、編輯、刪除寫入既有操作紀錄
- [ ] 新增合約單服務測試檔（記憶體庫、假使用者、假序號服務），覆蓋上述規則
- [ ] 專案編譯與全部測試通過
