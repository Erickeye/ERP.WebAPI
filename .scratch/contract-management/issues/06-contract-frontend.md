# 06: 合約單前端

**Spec:** `.scratch/contract-management/spec.md`

**What to build:** 使用者可以在畫面上完成合約單的整個流程：列表查詢、建立與編輯草稿、上傳與下載 PDF、送簽、撤銷、簽核人核准與拒絕、最後一關簽核人作廢。依專案前端規範撰寫（使用 `vue-coding-style` skill）。

**Blocked by:** 02、03、04

**Status:** ready-for-agent

- [ ] 列表頁：欄位、篩選（關鍵字、類型、對象、簽約公司、狀態、生效中／已到期、日期區間、待我簽核）、預設排序、分頁、新增與進入檢視入口，並顯示生效中／已到期標籤
- [ ] 建立、編輯、檢視共用一頁：類型切換時對象選單隨之改變，簽約公司選單排除停用者
- [ ] 草稿與已退回可儲存、上傳或更換 PDF、送簽、刪除（草稿）；簽核中可撤銷；簽核中、已核准、已作廢唯讀
- [ ] 輪到目前使用者簽核時顯示核准與拒絕（拒絕必填原因）；已核准且目前使用者為最後一關簽核人時顯示作廢
- [ ] 可下載 PDF；簽核進度沿用現有簽核進度查詢
- [ ] 新增路由與選單入口，依合約單檢視、編輯、刪除權限顯示頁面與按鈕
- [ ] API 封裝與錯誤處理比照現有頁面
- [ ] 前端建置通過
- [ ] 在瀏覽器手動驗證完整流程（交由使用者；未驗證則保持不勾並在 Comments 說明）
