# 04: 列表篩選與可見範圍（後端）

**Spec:** `.scratch/contract-management/spec.md`

**What to build:** 合約單列表提供完整篩選，已核准的合約單顯示「生效中」或「已到期」，簽核人能看到並篩選待自己簽核的合約單。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 有檢視權限的人看全部合約單；簽核人即使沒有檢視權限也看得到待自己簽核的單
- [ ] 篩選：關鍵字（單號、合約編號）、類型、合約對象、簽約公司、合約單狀態、日期區間（與起訖有交集）、待我簽核
- [ ] 已核准且今天介於起訖日（含起訖兩天）為生效中；已核准且今天晚於迄日為已到期；尚未到起日的已核准單不顯示標籤；不儲存
- [ ] 可依生效中或已到期篩選
- [ ] 預設依起日由新到舊，沿用專案分頁與排序寫法
- [ ] 「待我簽核」取自引擎現有的待簽核查詢並限定合約單
- [ ] 合約掃描檔下載（ticket 02 的 `DownloadAttachment`）套用同一可見範圍：簽核人沒有檢視權限也能下載待簽核單的掃描檔；列表與單筆目前掛的「合約單檢視」權限屬性一併處理
- [ ] 測試覆蓋可見範圍、各篩選、起訖當天與迄日隔天的邊界、排序與分頁
- [ ] 專案編譯與全部測試通過
- [ ] 列表查詢在真實資料庫的行為待使用者驗證（記錄於 Comments；未驗證則說明）
