# 05: 供應商、公司、客戶的刪除引用保護

**Spec:** `.scratch/contract-management/spec.md`

**What to build:** 被合約單引用過的供應商與公司只能停用、不能刪除；被合約單引用過的客戶不能刪除。這是修改既有的刪除檢查，不新增客戶停用功能，也不補其他單據對客戶的引用檢查。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 供應商刪除的引用檢查把合約單算進去，被引用時回明確訊息並建議停用
- [ ] 公司刪除的引用檢查把合約單算進去，被引用時回明確訊息並建議停用
- [ ] 客戶刪除新增「被合約單引用就擋下」一項檢查，其他行為不變
- [ ] 供應商刪除既有規則（被進貨單或庫存項目引用不可刪、報價連帶刪除）不變
- [ ] 延伸供應商服務測試與公司服務測試覆蓋新規則；客戶的測試放進合約單服務測試，不新增客戶測試檔
- [ ] 若現有測試因規則改變需要調整，已調整並在 Comments 記錄
- [ ] 專案編譯與全部測試通過
