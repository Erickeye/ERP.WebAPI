# 03: 送簽、核准、拒絕、撤銷、重送與作廢（後端）

**Spec:** `.scratch/contract-management/spec.md`

**What to build:** 合約單走簽核：建單人送簽，簽核人核准或拒絕，建單人可撤銷與重送已退回的單，最後一關簽核人可作廢已核准的單。五個簽核動作走合約單專屬端點，與單據狀態同一交易（依 `docs/attendance/adr/0001`），做法參考出差單。

**Blocked by:** 01、02

**Status:** ready-for-agent

- [ ] 新增合約單簽核目標轉接器並手動註冊；通用簽核控制器擋下合約單的送簽、核准、拒絕、撤銷、作廢（簽核進度與「待我簽核」查詢不擋）
- [ ] 狀態流轉：草稿 → 簽核中；簽核中 → 已核准（最後一關）／已退回（拒絕或撤銷）；已退回 → 簽核中；已核准 → 已作廢；已作廢為終態；中間關卡核准不改狀態
- [ ] 前置狀態檢查在引擎動作之前，錯誤訊息包含目前狀態
- [ ] 送簽時附件必填；送簽時重新驗證供應商與簽約公司未停用、對象存在
- [ ] 沒有啟用的簽核設定或有多組啟用設定時，把引擎的錯誤原樣轉出
- [ ] 供應商合約與客戶合約共用同一組簽核設定
- [ ] 拒絕必須填原因；還沒輪到的簽核人無法核准
- [ ] 簽核動作失敗時，簽核紀錄與合約單狀態一併回復
- [ ] 只有最後一關簽核人可作廢，指定人員與指定角色兩種簽核模式都適用；作廢後不可重送
- [ ] 已進入簽核中、已核准的單不受之後對象或公司停用影響
- [ ] 五個動作寫入既有操作紀錄
- [ ] 測試覆蓋上述規則（假簽核引擎，含狀態與簽核紀錄一併回復）
- [ ] 專案編譯與全部測試通過
