# 02: 進貨單串接：選單、存在檢查與送簽時停用檢查

**What to build:** 讓進貨單只能選啟用中的供應商，並在儲存與送簽時驗證供應商。填單用選單搬到供應商專屬端點並加權限；`SharedController.GetSupplierSelect` 暫時保留但只回傳啟用中；進貨單儲存時檢查供應商存在；送簽時檢查供應商是否啟用中。已送簽與已核准的進貨單不受停用影響。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] **先確認進貨單「送簽」的實際入口與檢查位置**（進貨單走舊簽核流程：`IsApproval`、`PurchaseApprovalTargetHandler`）；若沒有明確的送簽動作，先回頭更新 spec 再繼續，並在 Comments 記錄決定
- [ ] 供應商專屬端點提供填單用選單：只回傳啟用中；可指定一個供應商 Id，使已停用的該供應商一併回傳並標示已停用；選項同時帶出編號與名稱；只要求「進貨單編輯」或「庫存編輯」其中之一，不要求供應商檢視
- [ ] `SharedController.GetSupplierSelect` 保留，改為只回傳啟用中的供應商
- [ ] 進貨單新增與編輯儲存時，供應商不存在被擋下並有明確訊息（不改其他進貨單驗證）
- [ ] 進貨單送簽時，供應商已停用被擋下並提示改選；草稿與已退回的進貨單仍可編輯並顯示原停用供應商
- [ ] 已送簽或已核准的進貨單，供應商後來被停用，簽核與核准照常，且照常增加該供應商的庫存項目數量
- [ ] 延伸進貨單服務測試，覆蓋存在檢查、送簽停用檢查、已送簽與已核准不受停用影響；供應商服務測試補選單案例
- [ ] 供應商服務的引用判斷（ticket 01）與進貨單、庫存項目一致，並以種子資料驗證
