# 03: 送簽與重疊檢查

**What to build:** 建單人能把草稿送出簽核，單據變成簽核中並在前端轉為唯讀、顯示簽核進度。送簽時檢查同一位出差人是否已有日期重疊的有效出差單（簽核中或已核准），有重疊就擋下並指出衝突的單號與日期。依差勤 ADR-0001，簽核動作走出差單自己的專屬端點，並以單一資料庫交易包住「引擎動作 + 單據狀態」；同時讓通用簽核端點對出差單的五個動作（送簽、核准、拒絕、撤銷、作廢）一律回錯誤，避免繞過出差單邏輯。

**Blocked by:** 02

**Status:** resolved

- [x] 草稿可送簽，成功後狀態為簽核中；前置狀態不符時被擋下，訊息包含目前狀態
- [x] 送簽在單一交易內完成「引擎送簽 + 狀態更新」，引擎失敗時單據仍維持原狀態
- [x] 重疊檢查：同一出差人、狀態為簽核中或已核准、日期區間（含起訖兩天）有交集的其他出差單視為衝突；排除本單自己；衝突時列出單號與日期並擋下
- [x] 草稿、已退回、已作廢不參與重疊檢查；不檢查請假單與加班單
- [x] 沒有啟用的簽核設定時送簽被擋下並回「找不到啟用中的簽核設定」；同時有多組啟用設定時回設定重複的錯誤
- [x] 通用簽核端點對出差單的送簽、核准、拒絕、撤銷、作廢五個動作都回錯誤；簽核進度查詢不擋
- [x] 延伸現有通用端點守門測試，加入出差單五個動作被擋
- [ ] 簽核中的出差單在前端以唯讀顯示，並顯示現有簽核進度；前端有送簽按鈕
- [x] 服務測試覆蓋送簽成功、狀態不符、重疊衝突各種邊界（相鄰日不算重疊、同日算重疊、排除自己、狀態過濾）、交易回滾
