# 06: 作廢

**What to build:** 最後一關簽核人能作廢已核准的出差單（例如行程取消）。作廢後單據為終態，不可編輯、不可重送，要再出差就另開新單。作廢走出差單專屬端點，依賴 ticket 01 修正後的引擎作廢檢查，讓指定人員與指定角色兩種簽核模式下的最後一關簽核人都能作廢自己核准過的單。出差單沒有庫存要沖回，作廢只是終止單據。

**Blocked by:** 04, 01

**Status:** resolved

- [x] 作廢：只有已核准的出差單可作廢，其他狀態被擋下，訊息包含目前狀態
- [x] 作廢只允許最後一關簽核人（指定人員與指定角色皆可）；其他人被擋下
- [x] 作廢在單一交易內完成「引擎作廢 + 狀態更新」，失敗時整筆回滾
- [x] 作廢後單據狀態為已作廢，不可編輯、不可刪除、不可重送
- [x] 已作廢的出差單不參與同一出差人的重疊檢查，因此可另開同日期的新單
- [ ] 前端：已核准的出差單，只有最後一關簽核人看到作廢按鈕，作廢前有確認提示
- [x] 服務測試覆蓋作廢成功、非最後一關簽核人被擋、狀態不符、作廢後無法重送、作廢後可另開同日新單
