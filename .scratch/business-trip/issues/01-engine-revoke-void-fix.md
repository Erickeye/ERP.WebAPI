# 01: 簽核引擎：修正撤銷與作廢檢查

**What to build:** 讓簽核引擎的「撤銷」與「作廢」在指定人員與指定角色兩種簽核模式下都能正常運作。目前依程式所見，撤銷檢查的是最後一關待簽紀錄的簽核人而不是送簽人，所以建單人撤不了、角色簽核模式更是任何人都撤不了；核准時引擎也沒有把實際簽核人記到角色簽核的紀錄上，導致作廢檢查「只能作廢自己的簽核」在角色模式失效（拆 ticket 時請先再確認一次這個推論）。修正後，送簽人能撤銷自己送出且仍有待簽紀錄的簽核，最後一關簽核人能作廢自己核准過的單。共用引擎被修改，領料單、進貨單、請假單、公文同受影響，需確認既有行為與測試不被破壞。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 撤銷：操作者為送簽人，且流程仍有待簽紀錄時成功；非送簽人被擋下；沒有待簽紀錄時被擋下
- [x] 撤銷在指定人員與指定角色兩種簽核模式下都成功（角色模式不再因紀錄沒有 UserId 而失敗）
- [x] 核准時記錄實際簽核人，角色簽核的紀錄也能辨識是誰核准
- [x] 作廢：最後一關簽核人（指定人員與指定角色皆可）能作廢自己核准過的單；非該簽核人被擋下；流程未全部通過時被擋下
- [x] 新增以真實簽核引擎配記憶體資料庫的測試，覆蓋上述兩種簽核模式（不使用假引擎）
- [x] 現有領料單、進貨單相關測試全部通過；若有測試因假設變動而需調整，先回報再改
- [x] 完成後回報引擎變更對既有單據類型的影響範圍
