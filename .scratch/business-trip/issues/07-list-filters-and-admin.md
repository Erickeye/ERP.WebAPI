# 07: 列表篩選與管理權限

**What to build:** 使用者能在列表依單號關鍵字、出差人、出差單狀態與日期區間篩選出差單，日期區間以「與出差起訖有交集」為準。新增「出差單管理」權限，有此權限者能看到全部出差單，一般使用者仍只看到自己建立、自己出差或待自己簽核的單。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 篩選條件：單號關鍵字、出差人、出差單狀態、日期區間；可任意組合
- [ ] 日期區間以與出差起訖有交集為準（邊界日算有交集），不是只比對起日
- [ ] 預設依出差起日由新到舊，沿用專案現有分頁與排序寫法
- [ ] 新增「出差單管理」功能權限項目，依現有 Permission 機制設定；有此權限者可看全部單據
- [ ] 一般使用者的可見範圍（建單人、出差人、待我簽核）不因篩選而擴大
- [ ] 前端：列表頁加上篩選欄位與管理權限下的全部檢視
- [ ] 服務測試覆蓋各篩選條件、日期區間邊界、管理權限與一般使用者的可見範圍差異
- [ ] 列表查詢無法由記憶體資料庫完全驗證，須在 ticket 08 於真實資料庫確認
