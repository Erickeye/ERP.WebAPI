# 02: 出差單草稿：建立、編輯、刪除與基本列表

**What to build:** 讓有「出差單」權限的人能建立出差單草稿、編輯、刪除，並在列表看到自己建立或自己出差的出差單。從資料表、API 到前端頁面一次打通：建單人指定出差人（在職員工）、出差地點、出差事由、起訖日（可補單、可同日）、選填客戶與備註，系統自動產生單號並顯示出差天數。單據一開始是草稿，尚未送簽前都能修改。簽核相關動作留給後續 ticket。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 新增出差單資料表（單頭一張表）與既有資料庫用的 SQL 腳本，並同步資料庫專案與實體模型
- [ ] 單據類型列舉新增「出差單」（值 10），新增簽核目標處理器並註冊，使引擎能確認出差單存在
- [ ] 出差單狀態以列舉儲存（草稿、簽核中、已核准、已退回、已作廢）；本 ticket 只會產生草稿
- [ ] 單號為 `BT` + 民國年月 + 三位流水，沿用現有流水號服務
- [ ] 欄位驗證：出差人必須是在職員工；地點與事由必填；迄日不得早於起日；起日不設下限；客戶若填寫必須存在於客戶主檔
- [ ] 新增「出差單」功能權限項目，無權限者無法建單
- [ ] 草稿與已退回狀態可編輯，草稿可刪除；其他狀態編輯或刪除被擋下，訊息包含目前狀態
- [ ] 列表只顯示建單人或出差人為目前使用者的單，預設依出差起日由新到舊並分頁
- [ ] 前端：列表頁（新增、進入檢視）與建立／編輯頁，預設出差人為本人，顯示出差天數（迄日減起日加一，不存資料庫）
- [ ] 出差單服務測試（記憶體資料庫、假簽核引擎、假使用者、假流水號）覆蓋建立、編輯、刪除、欄位驗證與可見範圍
- [ ] 若新增了術語，更新差勤的 `GLOSSARY.md`
