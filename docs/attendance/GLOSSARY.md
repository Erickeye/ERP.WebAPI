# 差勤

管理員工因公離開公司的申請與簽核。目前涵蓋出差；請假、加班的用詞尚未整理。

## Language

**出差**:
員工因公前往公司以外的地點。不要求過夜或跨縣市，可當日往返。
_Avoid_: 外出、公出、外勤

**出差單**:
申請出差並送簽核的單據，記錄出差人、出差地點、出差事由與出差日期。只涵蓋事前申請，不含費用報支。
_Avoid_: 出差申請單、公出單、外出單

**出差人**:
實際前往出差的在職員工；可與建立出差單的人不同（例如主管或行政代填）。一張出差單只有一位出差人。
_Avoid_: 申請人、出差者

**出差天數**:
出差起日到迄日涵蓋的日曆天數，含起訖兩天、不扣假日；起迄同一天為 1 天。
_Avoid_: 出差日數、出差時數

**出差單狀態**:
出差單所處的階段：草稿、簽核中、已核准、已退回（被拒絕或被撤銷）、已作廢。
_Avoid_: 簽核狀態（那是簽核流程自身的狀態，不等同單據狀態）

**作廢**:
將已核准的出差單終止，例如行程取消；作廢後單據不可重送，需要時另開新單。
_Avoid_: 刪除、取消

**有效出差單**:
狀態為簽核中或已核准的出差單，代表這位出差人的這段期間已被占用。草稿、已退回、已作廢不算有效。
_Avoid_: 生效出差單、進行中出差單

**重疊**:
同一位出差人的兩張有效出差單，出差日期（含起訖兩天）有交集；前一張迄日與後一張起日是同一天也算重疊，相鄰但不同天不算。送簽時檢查，只比對出差單，不比對請假與加班。
_Avoid_: 衝突、撞期

**簽核人**:
在出差單的簽核紀錄中被指定（指定人員）或其角色被指定（指定角色）的人。不必是建單人或出差人，也不需要出差單功能權限；可檢視該出差單，輪到自己時可核准或拒絕。
_Avoid_: 審核者、主管（主管只是常見的簽核人，不是定義）

**待我簽核**:
出差單狀態為簽核中，且簽核流程已輪到目前使用者的出差單（前一關已通過、自己這一關尚未簽）。同一關有多人時，自己已核准、其他人未核准的單不算。
_Avoid_: 待辦、待審

**撤銷**:
送簽人在簽核流程完成前收回送出的簽核，單據變成已退回，可修改後重新送簽。只有送簽人（且為建單人或出差人）能撤銷；與簽核人的拒絕不同，但單據結果同為已退回。
_Avoid_: 取消、收回、作廢（作廢只用於已核准的單）

**最後一關簽核人**:
最近一輪送簽中，最後一關簽核紀錄上記錄的簽核人（指定人員為被指定的人，指定角色為實際核准的人）。只有最後一關簽核人能作廢已核准的出差單。被拒絕或撤銷後重送時，只看最近一輪。
_Avoid_: 最終審核者、最高簽核人

**出差單管理**:
功能權限項目，持有者可在出差單列表與檢視看到全部出差單。只放寬檢視範圍，不賦予編輯、送簽、撤銷、核准、拒絕、作廢；那些仍依各自規則（建單人或出差人、簽核人、最後一關簽核人）。
_Avoid_: 出差單管理員（那是持有此權限的角色，不是權限本身）、出差單全部檢視
