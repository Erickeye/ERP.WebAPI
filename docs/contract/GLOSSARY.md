# ERP 合約管理

管理我方與供應商、客戶簽訂的合約單據及其簽核。目前只記錄合約表頭與一份掃描檔，不含明細行、付款條件與到期提醒。

## Language

**合約單**:
記錄一份我方與某對象簽訂之合約的單據，需經簽核；記載簽約公司、合約對象、起訖日期、合約總金額與一份合約掃描檔。不取代供應商報價，也不影響進貨單與庫存。
_Avoid_: 合約、合約書、合約主檔

**供應商合約**:
合約對象為供應商的合約單。
_Avoid_: 採購合約

**客戶合約**:
合約對象為客戶的合約單。
_Avoid_: 銷售合約

**合約編號**:
紙本合約上的編號，由使用者輸入、必填；在非作廢的合約單之間不可重複，不分供應商合約或客戶合約。不同於系統自動產生的單號。
_Avoid_: 合約代號、合約號碼

**合約總金額**:
合約單上記載的單一金額，必填、大於 0；框架合約沒有固定金額時填預估金額。不是進貨或收款的實際金額。
_Avoid_: 合約金額、合約價

**合約對象**:
合約的另一方，依合約單的類型為一間供應商或一間客戶。
_Avoid_: 簽約對象、合約方、廠商

**簽約公司**:
合約單上代表我方簽約的那間公司（公司管理 context 的「公司」），建立合約單時必填。
_Avoid_: 我方公司、合約公司

**合約單狀態**:
合約單所處的階段：草稿、簽核中、已核准、已退回（被拒絕或被撤銷）、已作廢。「生效中」與「已到期」不是狀態，見下。
_Avoid_: 簽核狀態（那是簽核流程自身的狀態，不等同單據狀態）

**生效中**:
已核准的合約單，且今天落在其起訖日期之內（含起訖兩天）。由系統依日期計算，不儲存。
_Avoid_: 有效合約、進行中

**已到期**:
已核准的合約單，且今天已晚於其結束日期。由系統依日期計算，不儲存。
_Avoid_: 過期、失效

**作廢**:
將已核准的合約單終止，例如內容有誤或提前終止合約；作廢後單據不可重送，需要時另開新單。合約沒有獨立的「終止」狀態。
_Avoid_: 終止、解約、刪除、取消
