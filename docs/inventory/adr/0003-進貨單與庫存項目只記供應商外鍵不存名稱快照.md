# 進貨單與庫存項目只記供應商外鍵，不存供應商名稱快照

進貨單與庫存項目只存供應商主檔的 Id，顯示時即時查主檔；供應商改名、改統一編號視為「更正」，歷史單據也跟著顯示新資料，不另存簽核或入庫當下的快照。採用此做法是因為目前沒有「供應商更名但舊進貨單必須保留舊名稱」的法遵或對外文件需求，快照會讓每張進貨單多一組要維護的欄位，也與公司主檔的做法一致（公司管理 ADR-0001）。

## Considered Options

- **進貨單同時存供應商名稱與統編快照（送簽時寫入）**：歷史進貨單永遠顯示當時的名稱；但進貨單要多欄位、改名邏輯與回填更複雜，而庫存項目以供應商為單位，本來就無法保留舊名稱，目前沒有需求。

## Consequences

- 供應商主檔的名稱、統編被改動後，所有歷史進貨單與庫存項目立即顯示新值；若日後出現需保留舊名稱的需求（例如對外正式文件），需要加快照欄位並回填歷史資料。
- 因為只存外鍵，被進貨單或庫存項目引用過的供應商不可刪除，只能停用。
