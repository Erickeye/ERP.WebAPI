# 單據只記公司外鍵，不存公司名稱快照

領料單、出差單的單據公司只存公司主檔的 Id，顯示時即時查主檔；公司改名、改統編視為「更正」，歷史單據也跟著顯示新資料，不另存簽核當下的快照。採用此做法是因為目前沒有「公司更名但舊單據必須保留舊名稱」的法遵或對外文件需求，快照會讓每張單據多一組要維護的欄位。

## Considered Options

- **單據同時存公司名稱與統編快照（送簽時寫入）**：歷史單據永遠顯示當時的名稱；但每種單據要多欄位、改名邏輯與回填更複雜，目前沒有需求。

## Consequences

- 公司主檔的名稱、統編被改動後，所有歷史單據立即顯示新值；若日後出現需保留舊名稱的需求（例如對外正式文件），需要加快照欄位並回填歷史資料。
- 因為只存外鍵，被單據引用過的公司不可刪除，只能停用。
